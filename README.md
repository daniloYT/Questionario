# Questionário de requisitos – Fundação

Site estático (um único arquivo: `index.html`). Não precisa de build nem de servidor.

## Publicar no GitHub Pages
1. Crie um repositório novo no GitHub (público).
2. Envie `index.html` (e este `README.md`) para a raiz do repositório: *Add file → Upload files*.
3. Vá em **Settings → Pages**. Em *Build and deployment*, escolha **Deploy from a branch**, branch **main** e pasta **/ (root)**, e salve.
4. Após 1 a 2 minutos, o site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

As respostas ficam apenas na tela de quem preenche. Para guardar, use **Copiar relatório completo** ou **Imprimir / salvar em PDF**.
